# Design dials

Three proposals count as three only when each pair differs on at least four of these dials, and at least
one of the four is structural (navigation, density, hierarchy or grid).

| Dial | One pole | Other pole |
|---|---|---|
| Navigation | top bar with a few sections | side rail, or no chrome with in-page jumps |
| Density | one idea per screen, wide margins | many items per screen, tight rows |
| Hierarchy | one dominant element per section | several equal cards |
| Grid | single column, centred | asymmetric multi column, or full bleed |
| Type | one family, sizes do the work | two families, a display face for titles |
| Colour | near monochrome with one accent | several brand colours in blocks |
| Depth | flat, lines and space | layered, shadows and overlap |
| Imagery | product screens only | illustration, photos or pattern |
| Motion | static | scroll or hover motion that explains |
| Voice | plain labels | headline copy with a point of view |

## The two-proposal test

Put two proposals side by side and write, for each dial, which pole each one sits nearer. Fewer than four
different dials, or no structural one: rework the weaker proposal before sending the URLs.

Each proposal's top note names its idea in one line and the dials it pushes.
