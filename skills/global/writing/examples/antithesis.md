# Antithesis, rewritten

From outreach drafts. Say what the thing is.

| Don't write | Write |
|---|---|
| It is a growth tax, not an entry barrier | It only bites once things start working |
| chosen rather than stumbled into | worth picking on purpose |
| isn't a failure, it's the normal outcome | that's the normal ending |
| ...which is the point | Full stop, new sentence |
| the only genuinely new logic | the only new logic |

Also ration: tricolons, every paragraph landing a punchline, perfectly even sentence rhythm.
Density check: `grep -ocE "rather than|, not |which is|genuinely|precisely|exactly" <file>`.
